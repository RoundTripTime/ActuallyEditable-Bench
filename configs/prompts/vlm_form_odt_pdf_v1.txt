The attached images are the pages (in order) of one blank form document. Reconstruct it as ONE editable OpenDocument
text document that a person could open in a word processor and fill in.{pages_note}

The same document is also attached as a digital PDF with a text layer: ./input/form.pdf (the file the page images were
rendered from, unchanged). Use the PDF together with the page images.

The official OASIS OpenDocument 1.4 specification is attached in the directory ./odf_spec/:
- OpenDocument-v1.4-os-part3-schema.txt  (Part 3: OpenDocument Schema, plain text of the OASIS Standard)
- OpenDocument-v1.4-os-part2-packages.txt (Part 2: Packages)
- OpenDocument-v1.4-schema.rng            (normative RELAX NG schema)
Read these files (for example with grep or sed) and, before you answer, verify with them that every element and attribute
you use is allowed where you use it.
You may read the PDF with read-only commands, including python3 with its standard library only (for example zlib to
decompress its streams). Do not run any other command, and do not use any PDF library, converter or office application.

Output format: a single OpenDocument XML file (Part 3, section 3.1.2 <office:document>) with
office:mimetype="application/vnd.oasis.opendocument.text" and office:version="1.4", declaring every namespace you use.
Define page size and margins in a style:page-layout used by a style:master-page, put styles in office:styles and
office:automatic-styles, and put the content in office:body/office:text.

Rules:
- Reproduce every printed text exactly as shown (same language and characters); do not translate, summarise or fill anything in.
- Use real ODF tables (table:table with table:table-column, table:table-row, table:table-cell) for tabular layouts, with
  table:number-columns-spanned / table:number-rows-spanned and table:covered-table-cell for merged cells; keep empty input cells empty.
- Keep blank input areas as they appear (empty cells, underscores, spaces, brackets, "( )" etc.); checkboxes as □ or ☐ as printed.
- Keep headings, paragraph order, alignment and line structure; start every new page with a paragraph whose style has fo:break-before="page".
- Set widths, borders, alignment and font sizes through styles where they matter for the layout. No scripts, no external resources, no images.
- Answer with the complete XML document only (from <?xml version="1.0" encoding="UTF-8"?> to </office:document>), nothing else.
