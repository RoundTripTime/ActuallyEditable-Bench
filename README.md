# PDF에서 복원한 문서의 편집 용이성 평가

PDF 양식을 워드프로세서 문서로 복원할 때, 출력본과 비슷하게 보이는 문서라도 내용을 기입하거나 표의 구조를 수정하기 어려울 수 있습니다. 이 연구는 복원본의 **시각 유사도**와 **추정 편집 시간**을 함께 측정하여 복원 결과의 편집 용이성을 평가합니다.

## 평가 대상

동일한 출처에서 수집하고 수작업으로 검수한 원본 양식과 완성본 321쌍을 사용합니다. 원본 형식은 DOCX 235개, ODT 48개, HWPX 38개이며, 출처는 189개 웹 도메인입니다. 각 쌍의 원본과 완성본은 같은 형식입니다.

평가에 앞서 원본과 완성본을 ODT로 통일하고, 원본을 LibreOffice로 렌더링한 PDF를 출력본으로 사용합니다. 복원 방식에는 출력본만 제공하며 원본과 완성본은 제공하지 않습니다. Word와 한/글의 PDF 가져오기, Docling, GPT-6-Luna를 평가합니다. 원본 자체와 페이지 이미지를 삽입한 문서도 각각 대조군으로 평가합니다.

## 평가 지표

**시각 유사도**는 출력본과 복원본을 렌더링하여 같은 페이지끼리 비교한 SSIM의 평균입니다. 72 dpi 이미지에 표준편차 1픽셀의 가우시안 블러를 적용합니다. 누락된 페이지는 0점으로 처리하고, 추가 페이지는 평균에 반영하지 않고 페이지 넘침 비율로 별도 보고합니다.

**편집 시간**은 복원본을 완성본과 같은 내용과 표 구조를 갖고 대응 글자의 위치가 같은 페이지에서 가로·세로 12pt 이내인 문서로 만드는 데 필요한 시간의 추정값입니다. 문서를 문단, 표, 글상자, 이미지 등의 블록으로 나누고, 블록의 추가·변경·삭제를 포함한 편집 조합을 동적 계획법으로 구합니다. 글꼴, 정렬, 간격 등의 변경도 고려합니다. 각 작업의 시간은 키 입력, 포인터 이동, 클릭 등의 동작을 합산하는 KLM 모델로 추정합니다.

문서마다 필요한 수정량이 다른 점을 고려해 복원본의 추정 시간을 원본에서 같은 완성본을 만드는 추정 시간으로 나눈 배율로 보고합니다. 이 시간은 모델의 추정값이며 실제 사용자 작업 시간과 비교해 검증하지 않았습니다.

## 결과

편집 시간과 시각 유사도는 중앙값입니다.

| 방식 | 시각 유사도 | 편집 시간 배율 | 페이지 넘침 |
|---|---:|---:|---:|
| 원본 | 1.00 | 1.00 | 0.0% |
| Word | 0.73 | 2.34 | 26.8% |
| 한/글 | 0.71 | 2.49 | 17.1% |
| GPT-6-Luna | 0.73 | 2.67 | 34.9% |
| Docling | 0.71 | 2.77 | 20.9% |
| 이미지 | 0.99 | 3.51 | 0.0% |

원본의 추정 편집 시간 중앙값은 236초였습니다. 네 복원 방식은 표·문단 등의 블록을 추가하는 데 전체 추정 편집 시간의 54–64%를 사용했습니다. 여기에는 누락된 블록의 보완과 기존 블록을 삭제하고 다시 만드는 작업이 모두 포함됩니다. 위치 허용 범위와 입력 시간 가정을 바꾼 민감도 분석에서도 방식별 편집 시간의 순서는 유지됐습니다.

네 방식의 시각 유사도와 편집 시간 사이 스피어만 순위 상관계수는 −0.24였습니다. 시각 유사도가 0.9 이상인 54건에서도 편집 시간 중앙값은 원본의 1.98배였습니다.

자세한 내용은 [논문](paper/submission/review.pdf)을 참고하세요.

## 실험 실행

Python 3.10 이상이 필요합니다.

```bash
python3 -m venv .venv
. .venv/bin/activate
pip install -e '.[dev]'
python -m pytest
```

전체 실험에는 검수된 원본·완성본 데이터와 LibreOffice가 필요하며, 일부 변환에는 Windows의 Word·한/글과 외부 복원 도구 또는 모델 접근이 필요합니다. 기록된 실행 환경의 주요 버전은 **Microsoft Word 16.0 (빌드 16.0.14334)**, **한컴 한/글 13.0.0.564**, **LibreOffice 26.2.6.3**입니다. 변환과 렌더링은 프로그램 버전과 설치된 글꼴의 영향을 받습니다. 원본과 파생 문서를 포함한 데이터는 `data/`에 있습니다. 전체 실험에는 데이터 외에도 아래 도구와 실행 환경이 필요합니다. 수집과 권리 정책은 [권리 안내](docs/rights.md)를 참고하세요.

전처리는 [preprocess.py](scripts/preprocess.py)가 수행합니다. 원본과 완성본에 같은 변환 경로를 적용하고, 변환 손실과 시각 유사도를 기준으로 경로를 선택합니다. [run_experiment.sh](scripts/run_experiment.sh)는 전처리 후 복원을 실행하고, [evaluate.sh](scripts/evaluate.sh)는 시각 지표, 편집 비용, 민감도와 보고서를 계산합니다. 실행 인자와 환경 조건은 각 스크립트와 [실험 절차](docs/experiment.md)에 기록되어 있습니다.

주 결과와 민감도 분석은 [결과 보고서](reports/experiments/main/report.md)와 같은 폴더의 집계 자료에 있습니다. 구현은 `src/formbench/`, 설정은 `configs/`, 테스트는 `tests/`에 있습니다.
