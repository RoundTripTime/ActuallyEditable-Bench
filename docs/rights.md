# 데이터 수집과 공개

이 연구는 공개된 양식과 작성 예시를 수집해 같은 출처와 형식의 문서끼리 짝을 지어 검수했습니다. 웹에서 열 수 있다는 사실만으로 재배포 권한이 확인되는 것은 아닙니다. 원본 문서와 렌더링 이미지, 복원본을 포함한 파생 문서는 `data/`에 있습니다. 출처별 재배포 권한은 확인되지 않았습니다.

## 수집 설정

수집기는 출처별 접근 조건과 권리 규칙을 [설정 파일](../configs/rights_policy.yaml)에 따라 기록합니다. 현재 설정은 연구 목적으로 robots.txt를 가져올 수 없거나 접근이 금지된 경우에도 지연 시간을 두고 수집할 수 있도록 되어 있습니다. 이렇게 수집한 자료의 재배포 권한은 별도로 확인해야 합니다. 403·429 응답, CAPTCHA, 로그인 화면 또는 차단 화면은 우회하지 않고 해당 출처의 접근을 중단합니다. 연구 이용을 명시적으로 금지한 출처도 제외합니다.

이 설정은 출처별 이용 허가를 대신하지 않습니다. 자료를 다시 수집하거나 공개하려면 해당 출처의 조건과 재배포 권한을 확인해야 합니다.

## 개인정보와 삭제 요청

수집기는 개인정보로 보이는 패턴을 감지하면 검토가 필요한 문서로 표시합니다. 자동 검출만으로 개인정보가 없다고 보장할 수 없으므로 문서와 파생물의 공개 여부는 별도로 검토해야 합니다.

수집한 자료의 삭제 요청을 처리하는 명령은 다음과 같습니다. URL 패턴에 해당하는 자료와 파생물을 삭제하고 재수집을 차단합니다.

```bash
formbench collect takedown '<URL 패턴>' --reason '<사유>'
```
