# GPT-6-Luna에 디지털 PDF를 추가로 제공한 실험

주 실험에서는 GPT-6-Luna에 페이지 이미지와 ODF 명세를 제공했다. 이 실험에서는 같은 입력에 텍스트 층이 있는 디지털 PDF를 추가하여 321개 양식을 다시 복원했다. 두 조건의 결과는 같은 양식끼리 비교했다.

| 결과 | 주 실험 | PDF 추가 |
|---|---:|---:|
| 복원 성공 | 304/321 | 296/321 |
| 편집 시간 배율 중앙값 | 2.67 | 2.61 |
| 두 조건 모두 성공한 283건의 배율 중앙값 | 2.60 | 2.44 |
| 두 조건 모두 성공한 283건의 시각 유사도 중앙값 | 0.739 | 0.741 |
| 두 조건 모두 성공한 283건의 페이지 넘침 | 33.2% | 33.6% |

전체 321건에서 편집 시간 배율 중앙값의 차이는 −0.06이며, 출처 도메인 단위 부트스트랩으로 추정한 95% 구간은 −0.23~+0.05다. 두 조건 모두 성공한 283건의 차이는 −0.16이고 95% 구간은 −0.26~+0.02다. 두 구간 모두 0을 포함하므로 중앙값 차이의 방향을 확정하기 어렵다. 복원 실패는 빈 문서에서 시작한 편집 시간으로 반영했다.

PDF를 추가했을 때 대부분의 응답이 PDF를 읽었지만 지표의 변화는 작았다. 두 조건을 같은 시점에 반복 실행하지 않았으므로 모델의 실행 간 변동이 비교 결과에 미치는 영향은 분리할 수 없다. 이 보충 실험은 주 결과에 합산하지 않았다.
