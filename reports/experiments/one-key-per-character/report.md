# 문자당 키 입력을 1회로 고정한 결과

주 평가의 설정 중 문자당 키 입력을 1회로 고정해 복원 방식별 결과를 비교했다. 아래 값은 원본에서 완성본을 만드는 비용에 대한 복원본의 비용 배율 중앙값이다. 데이터와 나머지 평가 조건은 주 평가와 같다.

| 방식 | 비용 배율 중앙값 |
|---|---:|
| 원본 | 1.00 |
| Word | 2.33 |
| 한/글 | 2.46 |
| GPT-6-Luna | 2.65 |
| Docling | 2.77 |
| 이미지 | 3.17 |
