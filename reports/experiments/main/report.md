# 복원 방식별 평가 결과

321개 양식에 대해 원본에서 완성본을 만드는 추정 편집 시간과 복원본에서 같은 완성본을 만드는 추정 편집 시간을 비교했다. 아래 배율이 1이면 원본과 같은 시간이다. 시각 유사도는 1에 가까울수록 출력본과 비슷하며, 페이지 넘침은 출력본보다 복원본의 페이지가 많은 경우의 비율이다.

| 방식 | 시각 유사도 중앙값 | 편집 시간 배율 중앙값 | 페이지 넘침 |
|---|---:|---:|---:|
| 원본 | 1.00 | 1.00 | 0.0% |
| Word | 0.73 | 2.34 | 26.8% |
| 한/글 | 0.71 | 2.49 | 17.1% |
| GPT-6-Luna | 0.73 | 2.67 | 34.9% |
| Docling | 0.71 | 2.77 | 20.9% |
| 이미지 | 0.99 | 3.51 | 0.0% |

원본의 추정 편집 시간 중앙값은 236초였다. GPT-6-Luna에서 실패한 17건은 빈 문서에서 시작하는 것으로 편집 시간을 계산했으며, 시각 유사도와 페이지 넘침은 성공한 304건에서 계산했다. 다른 방식과 대조군의 시각 지표는 각각 321건이다.

네 방식의 시각 유사도와 편집 시간 사이 스피어만 순위 상관계수는 −0.24였다. 시각 유사도가 0.9 이상인 54건의 편집 시간 중앙값은 원본의 1.98배였다. 표·문단 등 블록의 추가는 네 방식의 전체 추정 편집 시간 중 54–64%를 차지했다. 추가에는 누락 보완뿐 아니라 기존 블록을 삭제한 뒤 다시 만드는 작업도 포함된다.

위치 허용 범위를 6pt 또는 24pt로 바꾸고, 키 입력 시간을 절반 또는 두 배로 바꾸거나 문자당 키 입력을 1회로 고정해도 방식별 편집 시간의 순서는 유지됐다. [민감도 자료](sensitivity.json)에서 조건별 결과를 확인할 수 있다.
